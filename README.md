## Publish with GitHub Pages

1. Upload the contents of this directory to the root of a dedicated GitHub repository, including `.nojekyll` and `downloads/`.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Open the URL shown by GitHub after deployment completes.

All page and download paths are relative, so the site supports a repository subpath. No package installation, build service, backend, or API credentials are required. Updates replace the published static files with a newly checked export.
