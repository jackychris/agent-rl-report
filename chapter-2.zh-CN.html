2. 背景与相关工作

2.1. 工具使用智能体的结果导向 RL 与过程监督

面向多轮工具调用的结果导向 RL 通过 PPO（Schulman et al., 2017）或 GRPO（Shao et al., 2024），在 Qwen3 系列等模型（Yang et al., 2025）上推动了 Search-R1（Jin et al., 2025）与 ReTool（Feng et al., 2025a）的终局准确率提升。然而终局得分上升并不能指明是哪种中间策略支撑了这一收益。在终端智能体研究中，Yao et al. (2026) 证明即使 SFT 后准确率相近，SFT 技能多样性仍主导后续 RL 泛化；他们同时指出，对结束前的核验行为给奖会抬高检查频次，必须配合重复惩罚才能提升终局成功率，这与本文 WebShop 访问奖励和 Ask-or-Act 路线分化一致。

在 token 级损失与单步更新条件下，Sullivan and Koller (2025) 证明终局奖励 GRPO 会在共享前缀上诱导出隐式蒙特卡洛过程奖励。显式奖励塑形是否有益，因此取决于它能否在该隐式信用之上提供有效区分。经典势能塑形通过 γΦ(s′)−Φ(s)\gamma \Phi(s') - \Phi(s)γΦ(s′)−Φ(s) 保持最优策略不变（Ng et al., 1999）。但在 GRPO 的组内标准差归一化下，Wang (2026) 证明当组内终局回报相等时，结果对比完全抵消而微小塑形项会被放大至全步长更新，这与 §6.1 的代数分析吻合。为抑制浅层指标刷分，结构化过程方法在 RLTR 中检查工作流完备性（Li et al., 2025），在 PROVE 中按依赖序检验参数与预算（Abdelaziz et al., 2026），在 AgentPRM 中训练步骤进度评价器（Choudhury, 2025; Xi et al., 2025），或在 Kimi K2 中引入校准准则裁判（Kimi Team, 2025）。Ask-or-Act 保持确定性执行器固定，并在测试时切换工具位置与数值规则以隔离行为退化（AskAct-EvalRL）。

2.2. 工具必要性与证据实际使用

过度或无依据的工具调用同时受到效率与归因研究的关注。Zeng et al. (2026a) 与 OTC-PO（Wang et al., 2025b）表明，纯结果奖励会容忍冗余工具调用，而联合效果-效率目标能够压低这些冗余。Wu et al. (2026)、ToolVision（Mao et al., 2026）与 Search-G1（Cheng et al., 2026）通过开关工具访问或移除检索片段来测定单次查询的必要性与答案依赖度。SMART（Qian et al., 2025）显式训练包含用户澄清回合的必要性推理，而 IGPO（Wang et al., 2025a）与 TIPS（Xie et al., 2026）利用当前策略或冻结策略下真值答案的对数概率增量给中间轮次打分。

多类诊断基准专门检验模型是否真实依据检索内容决策。RAGChecker（Ru et al., 2024）在断言层级分离检索召回与忠实度，ToolFailBench（Soni, 2026）检测输出是否服从模拟工具对参数先验的覆盖。HERALD（Liu et al., 2026b）插入反事实段落以识别虚假引用，Proof-of-Use（Ma et al., 2025）在训练中结合归一化证据编号与消融检验，AttriGuard（He et al., 2026b）则在相同动作前缀后改写观测以检测提示注入脆弱性。本文在 Ask-or-Act N 切片构造配对 (A, B) 分支对照，并在 WebShop 上从初始页独立重跑以测量整条交互协议差异。

2.3. GRPO 中的零方差组与候选动作多样性

当训练在简单题或难题上趋于饱和时，组内方差会归零。Zhou et al. (2026) 将 GRPO 策略梯度表述为 U 统计量以标定组采样规模，DAPO（Yu et al., 2025）与 Query Recycling（Coelho et al., 2026）则动态跳过或延后零方差组直至策略更新恢复分差。AVSPO（He et al., 2026a）注入极端合成回报以打破平局并保持真实 rollout 同权，CIGPO（Dou, 2026）在格式惩罚将全组压至 -2.0 时引入轮次信息增益。

第 6.1 节的 WebShop 采样普查按候选动作差异细分中间同分提示组。在 197 个低于满分的同分任务组中，有 121 组的八条 rollout 执行完全相同的环境动作序列，导致单纯重算评分时梯度对比度仍为零。PORTool 的分支 rollout 树（Wu et al., 2025）、OVCSD 的失败状态教师恢复（Xia et al., 2026）以及 ACT 的专家步骤对比批评（Liu et al., 2026a）均针对此类候选支撑缺失问题。

2.4. 步骤级信用分配、token 加权与 rollout–actor 对齐

无评论器的动作边界信用分配方法包括 GiGPO（Feng et al., 2025b）与 RTMC（Wang et al., 2026b）中的重复状态分组，这与本文第 6.2 节测试的 WebShop GiGPO 和 Ask-or-Act 状态锚点基线直接对应。ProGPO（Fan and Liu, 2026）对比精确前缀对等体，报告 WebShop 与 ALFWorld 分别有 33.7% 和 44.5% 的步骤在转移信用前缺少精确前缀同伴；TRIAGE（Xu et al., 2026）用大模型分配步骤角色权重，CAPO（Wang et al., 2026a）训练边界评论器，Agent Lightning（Luo et al., 2025）将智能体执行与轨迹训练解耦。

优化聚合与推理训练引擎一致性同样决定参数更新方向。DAPO（Yu et al., 2025）采用全局 token-mean 损失聚合，GSPO（Zheng et al., 2025）裁剪长度归一化序列比率。Balanced Aggregation（Zeng et al., 2026b）对不等长正负样本重加权，Token Gradient Cancellation（Ding et al., 2026）消除共享 token 上的权重漂移。张量并行归约误差（Zhang et al., 2025）、QaRL 量化漂移（Gu et al., 2026）以及 VeXact（Zhong et al., 2026）研究的 rollout 与训练器概率偏离，均对应本文中测得的单 token 极大偏离及 SGLang 与 FSDP 间 39.5× 序列与 token χ2\chi^2χ2 比值。
