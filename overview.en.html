Scores and Behavioral Evidence in Agent Reinforcement Learning

Author: Hao Fu

From Task Scores to Agent Behavior

Abstract

The same training run can improve action order on one task family while losing a required lookup on another. We study three routes within the Qwen3-8B family: supervised fine-tuning, GRPO after supervised fine-tuning, and GRPO directly from the initial Instruct model. Controlled Ask-or-Act tasks and deterministic trajectory replay compare target behaviors; WebShop visitation, text treatments, and grouped samples examine intermediate rewards and credit assignment.

Ask-or-Act contains 1,780 deterministic tasks across five simulated worlds. Continuing GRPO from an SFT model trained on 192 demonstrations raises original training-task success from 178/192 to 192/192. On 20 clarification–confirmation paired tasks, success stays at 20/20 while premature action falls from 19/20 to 0/20. On the same 60 two-tool numerical tasks, the same 50 tasks succeed at both checkpoints, but the count satisfying the pre-write lookup condition falls from 60/60 to 0/60. This condition includes trajectories that query and never write; premature action includes write attempts blocked by the environment. Direct GRPO achieves 58/60 pre-write lookups but retains action-condition errors, including intent mismatch. On 30 scheduling tasks requiring a returned tool identifier to be passed onward, direct GRPO succeeds on 30/30 but passes the returned identifier onward on only 6/30. Recorded trajectories show that user queries and recovery from blocked attempts can also complete the booking.

In WebShop, a visit reward raises rewarded-subpage visits from 94/500 to 498/499. Text-treatment conditions run separately from the initial page; saved purchase Booleans and complete action changes are reported separately. Post-training evaluation samples eight trajectories on each of 500 tasks. On 197 tasks, all eight returns are identical and strictly between zero and one, giving zero reward-derived advantages under standard GRPO. Of these, 121 also repeat identical environment-action sequences.

We organize these cases into diagnostic checks that use behavioral differences to locate problems in evaluation, sampling, or advantage computation. The report retains behavioral improvements and failed experiments across the three training routes. These experiments also raise a question about the training mechanism: to what extent does assigning positive advantage to an action make the model more likely to choose it?
